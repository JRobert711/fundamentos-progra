Instrucciones para ejecutar el código:
Ejecutar el archivo: Biblioteca_codigo.exe
Se mostrará un menú principal, cada numero a excepción del "0" abrirá un submenú correspondiente a la entidad a modificar.
Para salir de este menú solo se debe presionar la opción "0". Si se desea modificar el contenido de la base de datos,
primero debe listar los daatos ya existentes en cada submenú para ser conocedor del ID único de cada elemento.
